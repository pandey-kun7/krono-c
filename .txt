## **Lines 22-27: Struct `rio_t` (Buffered Reader)**

```c
typedef struct {
    int rio_fd;                 /* descriptor for this buf */
    int rio_cnt;                /* unread byte in this buf */
    char *rio_bufptr;           /* next unread byte in this buf */
    char rio_buf[RIO_BUFSIZE];  /* internal buffer */
} rio_t;
```

**Purpose:** Define a custom data structure for efficient buffered reading.

- `rio_fd`: The file descriptor (network connection) to read from
- `rio_cnt`: How many unread bytes are left in the buffer
- `rio_bufptr`: Pointer to the next byte to read
- `rio_buf`: The actual buffer array holding 1024 bytes

**In plain English:** This is like a "smart container" that reads data in chunks from a network socket, so we don't read one byte at a time (which is slow).

## **Lines 68-84: Function `writen()` (Write Data Safely)**

```c
ssize_t writen(int fd, void *usrbuf, size_t n){
    size_t nleft = n;
    ssize_t nwritten;
    char *bufp = usrbuf;

    while (nleft > 0){
        if ((nwritten = write(fd, bufp, nleft)) <= 0){
            if (errno == EINTR)  /* interrupted by sig handler return */
                nwritten = 0;    /* and call write() again */
            else
                return -1;       /* errorno set by write() */
        }
        nleft -= nwritten;
        bufp += nwritten;
    }
    return n;
}
```

**Purpose:** Send data over the network, handling interruptions and partial writes.

- **Line 69**: `nleft = n;` - Keep track of how many bytes are left to write
- **Line 70**: `nwritten;` - Store how many bytes were actually written
- **Line 71**: `bufp = usrbuf;` - Point to the start of data to send
- **Lines 73-82**: Loop until all bytes are sent
  - **Line 74**: Try to write `nleft` bytes
  - **Lines 75-76**: If interrupted by a signal, retry (don't give up)
  - **Line 78**: If real error, return -1
  - **Lines 80-81**: Update tracking: reduce bytes left, move pointer forward
- **Line 83**: Return success (all bytes sent)

**In plain English:** "Keep sending data until it all gets out, even if interrupted."

## **Lines 96-120: Function `rio_read()` (Read Data Buffered)**

```c
static ssize_t rio_read(rio_t *rp, char *usrbuf, size_t n){
    int cnt;
    while (rp->rio_cnt <= 0){  /* refill if buf is empty */

        rp->rio_cnt = read(rp->rio_fd, rp->rio_buf,
                           sizeof(rp->rio_buf));
        if (rp->rio_cnt < 0){
            if (errno != EINTR) /* interrupted by sig handler return */
                return -1;
        }
        else if (rp->rio_cnt == 0)  /* EOF */
            return 0;
        else
            rp->rio_bufptr = rp->rio_buf; /* reset buffer ptr */
    }

    /* Copy min(n, rp->rio_cnt) bytes from internal buf to user buf */
    cnt = n;
    if (rp->rio_cnt < n)
        cnt = rp->rio_cnt;
    memcpy(usrbuf, rp->rio_bufptr, cnt);
    rp->rio_bufptr += cnt;
    rp->rio_cnt -= cnt;
    return cnt;
}
```

**Purpose:** Read data from the network connection efficiently using a buffer.

- **Line 98**: If buffer is empty, refill it
- **Lines 100-101**: Read up to 1024 bytes from the network into `rio_buf`
- **Lines 102-107**: Handle read errors and end-of-file
- **Line 109**: Reset pointer to start of buffer
- **Lines 113-115**: How many bytes should we copy? The minimum of what the user asked for (`n`) or what's in the buffer (`rio_cnt`)
- **Line 116**: Copy bytes to the user's buffer
- **Lines 117-118**: Update pointer and counter
- **Line 119**: Return how many bytes we copied

**In plain English:** "Read data in chunks for efficiency, serving bytes as needed."

ssize_t rio_readlineb(rio_t *rp, void *usrbuf, size_t maxlen){
    int n, rc;
    char c, *bufp = usrbuf;

    for (n = 1; n < maxlen; n++){
        if ((rc = rio_read(rp, &c, 1)) == 1){

**Purpose:** Read one line from the network (up to `maxlen` characters), stopping at newline.

## **Lines 346-378: Function `process()` (Handle One Request)**

```c
void process(int fd, struct sockaddr_in *clientaddr){
    printf("accept request, fd is %d, pid is %d\n", fd, getpid());
    http_request req;
    parse_request(fd, &req);

    struct stat sbuf;
    int status = 200, ffd = open(req.filename, O_RDONLY, 0);
    if(ffd <= 0){
        status = 404;
        char *msg = "File not found";
        client_error(fd, status, "Not found", msg);
    } else {
        fstat(ffd, &sbuf);
        if(S_ISREG(sbuf.st_mode)){
            if (req.end == 0){
                req.end = sbuf.st_size;
            }
            if (req.offset > 0){
                status = 206;
            }
            serve_static(fd, ffd, &req, sbuf.st_size);
        } else if(S_ISDIR(sbuf.st_mode)){
            status = 200;
            handle_directory_request(fd, ffd, req.filename);
        } else {
            status = 400;
            char *msg = "Unknow Error";
            client_error(fd, status, "Error", msg);
        }
        close(ffd);
    }
    log_access(status, clientaddr, &req);
}
```

**Purpose:** Handle one client request from start to finish.

1. Parse the HTTP request
2. Try to open the requested file
3. If not found, send a 404 error
4. If it's a regular file, send it
5. If it's a directory, generate and send a directory listing
6. Otherwise, send an error
7. Log the request

## **Lines 418-431: Fork Child Processes**

```c
    for(int i = 0; i < 10; i++) {
        int pid = fork();
        if (pid == 0) {         //  child
            while(1){
                connfd = accept(listenfd, (SA *)&clientaddr, &clientlen);
                process(connfd, &clientaddr);
                close(connfd);
            }
        } else if (pid > 0) {   //  parent
            printf("child pid is %d\n", pid);
        } else {
            perror("fork");
        }
    }
```

**Purpose:** Create 10 child processes to handle requests in parallel.

- `fork()`: Create a new process
- Child process (pid == 0): Accept connections in a loop and process them
- Parent process (pid > 0): Just print the child's ID
- On error (pid < 0): Print error

**In plain English:** "Spawn 10 worker processes, each handling client requests."

- `close()`: Close the connection
